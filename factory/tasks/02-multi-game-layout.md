# Factory task 02: Multi-game layout

## Goal
Separate the generic factory from the game it builds, so a second game is a
new folder and a new spec. No behavior changes.

## Target layout
    factory/                  generic: README, tools, tasks (factory work only)
    .claude/                  agent and command definitions (task 03)
    games/egg-champions/
      spec.md                 was spec/egg-champions.md
      config/                 generated by agent 1
      tuning/                 generated by agent 2
      src/                    game code
      default.project.json    Rojo project, paths relative to this folder
      roblox.json             universe and place IDs
      tasks/                  build tasks for this game
      notes/                  was factory/notes
    rokit.toml, selene.toml, stylua.toml, CLAUDE.md, .gitignore stay at the root

## Build
1. Move files with `git mv` so history is kept.
2. Move `factory/tasks/01-project-skeleton.md` to
   `games/egg-champions/tasks/01-project-skeleton.md`. Factory briefs
   (02 onward) stay in `factory/tasks/`.
3. Make every factory tool take the game folder or explicit paths as
   arguments. No path to a specific game hard-coded in `factory/`.
4. Fix `default.project.json` paths, the build output path
   (`games/egg-champions/build/`), and `.gitignore`.
5. Update `CLAUDE.md`, `factory/README.md`, and the agent instruction files
   to the new paths.
