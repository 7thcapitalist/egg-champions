# Egg Champions and the game factory

This repo holds the factory of agents that builds Roblox games, and the games it
builds. Read `factory/README.md` first.

## Layout
- `factory/`: generic. Nothing here names a game.
  - `factory/agents/`: instructions for each agent.
  - `factory/tools/`: the agents' scripts. Python standard library only.
    Every tool takes the game folder or explicit paths as arguments.
  - `factory/tasks/`: briefs for factory work itself. One at a time, in order.
- `games/<game>/`: one game. A new game is a new folder and a new spec.
  - `spec.md`: the game design. Source of truth for every number.
  - `config/`: generated from the spec by agent 1. Never edit by hand.
  - `tuning/`: generated by agent 2 (gym stats, pacing report).
  - `src/`: game code (Luau), synced into Roblox with Rojo.
  - `default.project.json`: Rojo project. Paths are relative to this folder.
  - `roblox.json`: universe and place IDs for production and test.
  - `tasks/`: build briefs for this game. One at a time, in order.
  - `notes/`: findings from experiments.
  - `build/`: Rojo output. Ignored by git.
- `rokit.toml`, `selene.toml`, `stylua.toml`: one toolchain for every game.

The game built so far is `games/egg-champions` (Egg Champions: Pet Clicker
Simulator).

## Rules
- To change a game number, change that game's spec, then rerun agent 1 and
  agent 2. For `games/egg-champions`:
  `python factory/tools/parse_spec.py games/egg-champions/spec.md games/egg-champions/config`
  `python factory/tools/validate_config.py games/egg-champions/config`
  `python factory/tools/simulate_economy.py games/egg-champions/config games/egg-champions/tuning`
- Game code reads numbers from config. No game numbers hard-coded in `src/`.
- The server decides everything that matters (coins, hatches, battles).
  The client only sends requests and shows results.
- `.env` holds the Roblox API key. Never read it aloud, print it, or commit it.
- Only publish to the test place. Publishing to production needs the owner's OK.
- Luau files use `--!strict`. Run `selene games/<game>/src` and
  `stylua games/<game>/src` before committing.
- All pets and characters are original designs. Never use names, likenesses,
  or assets from Pokemon or any other existing franchise.
- No em dashes in any file.
- When a brief is done, tick its checklist, commit, and push.
